# Projeto AMILV
## Criação de Website
Criação de um website utilizando HTML, desenvolvido para uma ONG/Microempresa, como parte das atividades acadêmicas da disciplina

### Aula: Desenvolvimento Front-End Para Web
Membros do grupo
- Yuri Bezerra Rodrigues Silva
- Lucas Trevezan Lima
- Theo Carlo Oliveira Modesto
- David Alejandro Delgado Mendoza
- Felipe Domingos de Lacerda

ONG escolhida: AMILV - Associação de Mulheres Imigrantes Luz y Vida.

O objetivo deste projeto é desenvolver um site institucional para a AMILV, apresentando informações sobre a organização, sua história, missão, formas de atuação e possibilidades de participação e voluntariado.
Além de apresentar a ONG, nosso projeto busca aplicar conceitos fundamentais de desenvolvimento Front-End, organização estrutural de páginas e construção de interfaces utilizando HTML básico.

Durante o desenvolvimento do projeto, utilizamos o agente de Inteligência Artificial Claude como uma ferramenta de apoio para:
- Revisão da estrutura dos códigos.
- Auxílio durante o desenvolvimento.
- Esclarecimento de dúvidas relacionadas ao HTML e à estrutura do projeto.

Além de utilizarmos o W3C Validator para correções pôs alterações.
